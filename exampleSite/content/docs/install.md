---

## As a Hugo module

```bash
hugo mod init github.com/you/your-site
hugo mod get github.com/PhantomPixelDev/hugo-theme-retrocss
```

## As a submodule

```bash
git submodule add https://github.com/PhantomPixelDev/hugo-theme-retrocss themes/hugo-theme-retrocss
```
